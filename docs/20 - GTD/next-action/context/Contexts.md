# Contexts List

The contexts page is the list of execution contexts and their related items.

| Shortcut | Scope | Action |
| --- | --- | --- |
| `a` | List | Add new context. |
| `d` | List or detail | Delete selected context. |
| `u` | List or detail | Undo last deletion. |
| `Ctrl+r` | List or detail | Redo last action. |
| `Enter` | List | Edit selected context. |
| `e` | List or detail | Edit context icon. |
| `j` | List | Move selection down. |
| `k` | List | Move selection up. |
| `l` | List | Focus context detail. |
| `h` | Detail | Focus contexts list. |
| `Escape` | Icon editor | Close icon editor. |
| `Space k` | List, detail, or icon editor | Show available keybindings. |
