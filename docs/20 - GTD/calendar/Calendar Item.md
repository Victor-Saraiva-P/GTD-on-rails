# Calendar Item

A calendar item is work that is bound to a specific date, with an optional time. It represents work that must happen on that date rather than work that merely has a latest acceptable completion date.

A next action with a deadline does not become a calendar item when its deadline arrives. It may be projected into Calendar views for operational awareness while retaining its Next Action identity.

## States

### Calendar

An active calendar item is scheduled for a specific date and may include a specific time.

### On Going

An on going calendar item has been intentionally pulled into active execution.

### Completed

A completed calendar item has been marked done.

### Deleted

A deleted calendar item is removed from active operational use but remains recoverable.
