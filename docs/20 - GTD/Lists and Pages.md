# Lists and Pages

Each main page is an operational GTD list. A list is not just a view: it is the place where items of a specific workflow state are selected, inspected, edited, recovered, deleted, or moved forward.

Use `Space k` on any page to show the available keybindings for the active screen and focus zone.

## Master-List Navigation

Master lists support shared Vim-style boundary motions in their list focus zone.

| Shortcut | Action |
| --- | --- |
| `gg` | Move selection to the first item. |
| `G` | Move selection to the last item. |

These master-list motions apply to Inbox, Deleted Inbox, Next Actions, On Going, Done Next Actions, Deleted Next Actions, and Contexts. They do not apply to Calendar panels.
